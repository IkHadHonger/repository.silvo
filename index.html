SiLVO Development Repository

Pre-release testing for Aeon Nox: SiLVO and related addons

⚙️ Prerequisites

Before installing, enable these settings in Kodi:

  1. Settings → System → Add-ons → Unknown sources → Enable
  2. Settings → System → Add-ons → Update official add-ons from → Any repositories

📦 Quick Install (Recommended)

  1. Download the repository addon:
    ⬇ Download repository.silvo-1.0.0.zip
  2. In Kodi, go to: Settings → Add-ons → Install from zip file
  3. Navigate to the downloaded zip file and install it
  4. The repository will auto-update from GitHub Pages

🌐 Install from File Manager (Alternative)

  1. In Kodi, go to: Settings → File Manager → Add source
  2. Enter this URL: https://mikesilvo.github.io/repository.silvo/
  3. Name it: SiLVO Repo
  4. Go to: Settings → Add-ons → Install from zip file
  5. Select SiLVO Repo and install repository.silvo-1.0.0.zip
⚠️ Important: This repository contains pre-release software for testing purposes. Stable versions are available in the official Kodi repository. Only use this if you want to help test new features.

🔧 Requirements

  • Kodi Piers (22.x) or newer
  • "Unknown sources" enabled for initial installation
  • Internet connection for updates
